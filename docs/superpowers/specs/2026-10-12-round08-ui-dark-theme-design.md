## 1. 왜

후배 기획자의 시각 디자인 작업이 대회 일정(10/23 기능 동결, 10/26 대회)에 맞추기 어려워, 사용자와 정책을 정해 Claude 가 화면 코드를 직접 바꾼다. 테마(색·유리 느낌·글꼴)는 후배 시안을 따르고, 화면 구성·버튼 자리는 아래 정책을 따른다(시안의 구성은 따르지 않는다).

- 테마 참고: Figma `y5romJwQdC7mMRD81smCjL` '임시 UI 개선' 페이지 — `2536:16697`(메인)·`2536:16720`(검색 결과)·`2539:19954`(결과 + 오른쪽 DeepRead)·`2536:16714`(상세)·섹션 `component`(`2282:13335`).

## 2. 정책 (사용자 결정 2026-10-12)

1. **테마 — 앱 전체 다크 글래스.** 짙은 초록 그라데이션 배경, 반투명 유리 카드(배경 흐림), 밝은 글씨, 포인트는 산호색(DeepRead 버튼 색), 로고 세리프 'skovix'. 색은 `:root` 변수로만 정의하고 화면은 변수만 쓴다. 딥리서치 화면(`research.css`·`work.css`)은 이미 변수만 쓰므로 같은 변수로 따라오고, 06d·06e 머지 뒤 남는 색을 맞춘다.
2. **메인 — 세 갈래 전환** [소장자료 검색 · 논문 검색 · 딥리서치]. 딥리서치는 논문 검색의 깊은 모드(입력창 + 메뉴·슬래시 명령은 그대로). 입력창 아래 예시 질문 카드(운영 검증 예시 — `project_demo_corpus_examples`). 도서 AI 컬렉션은 없앴으므로 '큐레이션 N권' 고르기를 뺀다. 도서 검색은 '소장자료 검색'으로 부른다.
3. **사이드바 — [새 검색] · 딥리서치 묶음 · 최근 검색.** 딥리서치 묶음은 진행 중 배지·상태, 최근 검색은 소장자료·논문을 시간순으로 섞고 종류를 표시한다. 기록 불러오기·폴링 로직은 바꾸지 않는다(06d N3·06e H2 가 붙일 자리).
4. **검색 결과 — 소장자료·논문 같은 틀.** 위 검색창 → AI 결과 2단(왼쪽 핵심 요약 접고 펼치기 · 오른쪽 참고 자료 1~5) → '총 N건 · 정렬' → 카드 목록. 카드: 왼쪽 표지, 가운데 관련도·키워드 칩·제목·서지, 오른쪽 버튼 열([원문 보기] [인용] / 강조 [DeepRead]). 06d N4 [딥리서치로 더 깊게]·N6 [담기] 자리는 AI 결과 아래에 둔다. 소장자료의 AI 결과는 **1위 도서 한 권 + 질문 기준 추천 이유**(초기 SKOVIX 와 같게 — 사용자 결정 2026-10-12), 컬렉션 호출은 걷는다.
5. **DeepRead — 결과 카드에서도 오른쪽 패널로 바로.** 논문 검색 AI 참고 카드에 이미 있는 옆 패널을 쓴다(새 부품을 만들지 않는다 — 06e R4 의 딥리드 패널과 겹치지 않게).
6. **목업 숨김.** 저장목록·북마크·프로필·설정처럼 누르면 '준비 중'만 뜨는 것은 대회 전에는 보이지 않게 한다(코드는 남긴다).
7. **상세 화면(도서·논문) — 틀은 다크, 읽는 면만 밝게(사용자 결정 2026-10-12).** 사이드바·배경은 다크로 두고, 본문을 읽는 큰 카드(서지·AI 요약·초록·연관·참고문헌)는 종이처럼 밝은 면으로 둔다. 구현은 밝은 면 클래스 하나가 그 안에서 색 변수를 밝은 값으로 다시 정의하는 방식 — 안쪽 부품은 손대지 않아도 밝게 그려지고, 06d·06e 가 딥리서치 보고서에 같은 클래스를 쓸 수 있다. 구성 개편은 하지 않는다.
8. **보존** — `/search-classic` 은 지우지 않는다(`feedback_preserve_search_classic`). 테마 변수 때문에 색이 달라지는 것은 괜찮다.

## 3. 범위 밖

서버(fastapi·워커) 변경 없음. 딥리서치 화면의 배치·동작(06d·06e 몫), 로그인·저장목록 실제 기능, 상세 화면 구성 개편은 하지 않는다.

## 4. 순서·충돌

- round08 을 먼저 `dev` 에 머지한다(목표 10/15, 사용자 승인). 06d·06e 는 시작할 때 그 `dev` 를 받고, 겹치는 작업(06d N1 문구·N3 사이드바 단계 표시·N4·N6, 06e R6 사이드바 접기·H2 기록 total)만 새 화면에 맞춰 붙인다.
- 06c 는 서버만 바꾸므로 겹치지 않는다.

## 5. 검증

- 기존 vitest·`nuxi typecheck`·`nuxt build` 통과. 문구·구조가 바뀐 곳의 테스트는 새 정책에 맞춰 고친다.
- 로컬 화면을 운영 API 에 붙여 띄워(`NUXT_DEV_API_TARGET=https://skovix.landsoft.co.kr/api npx nuxi dev --port 3005`) 메인·소장자료 결과·논문 결과·사이드바·상세·딥리서치 화면을 스크린샷으로 확인한다. 사용자도 같은 주소(`http://localhost:3005`)로 볼 수 있다.
- 다크 배경 글씨 대비(본문 4.5:1 이상).
