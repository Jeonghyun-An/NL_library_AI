# 검색 결과 — 최상위 1권 자동추천 + 동반책 추천 설계

작성일: 2026-09-15
상태: **논의 초안** (타 기획자 검토 대기, 구현 미착수)

## 배경

2026-09-15 회의 결과:
- 우선순위는 도서관대회 시연 준비. 신규 기능 에드온보다 **기존 검색·추천·대화 프로세스 강화**에 집중.
- 검색 후 사용자가 자료를 하나하나 선택하는 대신, **최상위 1권에 자동으로 큐레이션 추천이유**를 생성하고 **함께 보면 좋은 책을 LLM이 자동 추천**하는 방향으로 전환.
- 우측 영역은 "분석" 성격의 신규 기능보다 기존 검색·추천·대화 기능을 강화하는 쪽으로(예: 여러 책과 함께 대화하기).
- 지시사항: "지금 되어 있는 기존 화면과 기능에서 문제점을 찾고 그걸 기획으로 풀어내라."

## 이번 라운드 범위

우선순위 3가지(①최상위 1권+동반책 추천 ②멀티북 챗 ③검색/답변 품질 자체 개선) 중 **①만** 이번 라운드로 확정. ②·③은 다음 라운드로 이월. 도서 검색만 다루고 논문 검색(`/papers`)은 별도 화면이라 이번엔 제외.

## 결정된 방향

**레이아웃** — 검색 결과 리스트 맨 위에 히어로 카드(최상위 1권: 표지+추천이유) + 그 아래 "함께 보면 좋은 책" 동반책 스트립. 기존 평범한 리스트는 그대로 유지하되, 히어로/동반책에 해당하는 항목엔 "위에서 추천됨" 배지만 추가(리스트에서 빼지 않음 — 같은 책이 두 번 보여도 혼란 없다고 판단).

**DeepRead 연결** — 히어로 카드의 "DeepRead로 대화하기" 버튼을 누르면 **화면 전환 없이 카드 바로 아래에서 대화창이 인라인으로 펼쳐짐**(페이지 이동 방식 대신 채택 — "이어지는 경험"이 더 자연스럽다는 판단).

**우측 옛 "AI 큐레이션 분석" 패널** — 완전 제거. 빈 자리를 지금 다른 것으로 채우지 않음(YAGNI). 단, 다음 라운드 멀티북 챗의 진입점 후보 자리로 메모만 해둠. 1권 DeepRead(인라인)와 멀티북 챗(차기)은 서로 다른 진입점이라 희석 우려는 낮다고 판단.

**아키텍처** — 기존 `/api/books/curate`는 건드리지 않고 **새 엔드포인트 신설**(가안 `POST /api/books/curate/top`), `curator.py`에 `curate_top_pick()` 별도 함수 추가. 기존 라이브 기능 리스크 없이, 문제 생기면 바로 롤백 가능하게. 프롬프트는 1번 책=독립적 이유, 2번째부터(동반책)=1번 책과의 연결고리를 명시하는 구조로 분리. 동반책 개수는 기존 "묶음 크기" 설정(3/5/10/20)을 그대로 재사용 = 1권 + 동반(크기-1)권.

**활용 가능 자산** — `read_effect`(독후효과)가 이미 인덱싱 시 생성돼 있는데 프론트에 전혀 안 쓰이고 있음. 쿼리 시점 LLM 호출 없이 바로 쓸 수 있는 데이터라, 히어로 카드에 "이 책을 읽으면 얻는 것" 같은 형태로 곁들이는 걸 고려해볼 만함(신규 LLM 비용 없음).

**로딩/실패** — 로딩 중엔 기존과 동일한 타이프라이터 효과. 새 엔드포인트 실패 시 히어로/스트립 섹션만 숨기고 검색 결과 자체는 항상 정상 노출(전체 검색 흐름을 막지 않음).

**부수 정리** — `index.vue`의 죽은 코드(위 진단표 참고)는 이번에 히어로 영역을 새로 넣으면서 같이 걷어내는 걸 제안.

## 논의가 필요한 점 (다른 기획자와 확인 필요)

1. **동반책 개수/문구** — 기존 "묶음 크기" 설정(3/5/10/20)을 그대로 재사용하면 동반책이 최대 19권까지 될 수 있음. 스트립 UI로 몇 권까지가 적절한지 (예: 스트립은 최대 3~4권만 보여주고 나머지는 배지만? 아니면 묶음 크기 자체를 이 기능 전용으로 별도 상한을 둘지)
2. **히어로 카드 액션** — 현재는 DeepRead 버튼만 넣고 원문보기 등은 아래 리스트 카드에 맡기기로 했는데, 이게 충분한지 재확인 필요
3. **`read_effect` 활용 여부** — 위에서 제안한 "곁들이기"를 이번 라운드에 포함할지, 아니면 별도 작은 작업으로 분리할지
4. **우측 빈 공간** — 정말 비워둘지, 아니면 다른 기획자가 검토 중인 다른 아이디어가 있는지
5. **엔드포인트/함수 이름** — `curate/top`, `curate_top_pick()`은 가안. 팀 네이밍 컨벤션에 맞게 조정 필요
6. **README §10.3 정정** — 이미 구현된 기능이 "계획"으로 남아있는 문서 오류. 이번 라운드에 같이 고칠지 별도로 할지
