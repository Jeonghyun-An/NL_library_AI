## 표기 시 반드시 지킬 것
- 질의는 문서 내용에서 LLM 이 합성한 것이다. **실사용자 질의가 아니며**, 수치는 '합성 질문 기준'이라고 적는다.
- 정답은 질의의 원문서 1건이다. 같은 주제의 다른 문서는 정답이 아니므로 Recall·MRR·nDCG 는 하한이다.
- '문서 필드 기반' 질의(주제어·기관+연도·초록 첫 문장)는 **자연어 검색 정확도로 표기하지 않는다.**
- BM25 기준선은 제목·주제어·초록(없으면 소개)만 색인한 키워드 통합검색이다. 본문 전체 색인과의 비교가 아니다.
- OTR 은 LLM 판정이다. 사람 검증: 미실시(review-sheet 로 확인 필요). 다른 LLM 교차 확인(사람 아님): Claude 60쌍 일치율 81.7%, kappa 0.63.
- **OTR@10 의 절대값을 '정확도'로 읽지 않는다.** 질문에 맞는 문서가 코퍼스에 2건뿐이면 OTR@10 은 아무리 잘해도 20% 가 상한이다. 방식 간 상대 비교(예: BM25 대비 몇 배)로만 쓴다.
- ⚠️ **OTR 판정 모델(llm=gemma)이 질문 합성·질의 재작성·메타필터에도 쓰였다.** `SKOVIX + 질의 재작성`·`SKOVIX 전체`의 OTR 은 순환 가능성이 있어 단정하지 않는다. 순환이 없는 비교는 BM25 → 하이브리드 → +리랭커 구간이다.
- 지연시간·만족도·'찾는 시간 단축'은 이 실험이 측정하지 않았다.
