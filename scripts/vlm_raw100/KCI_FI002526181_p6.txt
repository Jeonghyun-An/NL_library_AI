Effect University Students’ experience with sanitary products except for disposable sanitary pads

[표 1] 면생리대 사용 경험
[Table 1] Experience with cotton sanitary pad

| 중심의미 | 주제 | 원자료 |
|---|---|---|
| 불안감 | 냄새 | 가끔씩 쉬는 시간 없이 수업하시는 교수님들 강의 들으면 교체하는 게 너무 힘들 거 같고… |
| | | 냄새가 그냥 피비린내가 나. 확실히 그 살짝 찌린내 같은 거 있잖아, 그런 건 없어. 근데 면생리대를 쓰면 그런 건 없는데 피비린내는 나. 그래서 조금 민망한 경우가 있지. |
| | | 나중에는 그냥 밀봉하면 냄새는 안 나거든. 근데 느끼기에 내가 지금 생리를 몸에 지니고 있다고 인식하는 순간 조금, 그지. 냄새날까봐 불안하기도 하고. 안 나는데 나만 느끼는 거 같기도 하고. |
| | | 냄새도 너무 심해서 다른 친구들에게도 냄새가 날까봐 너무 불안했어요. |
| | 두려움 | 자칫 잘못하면 쓸 수 있다는 게 보인다는 거. |
| | | 난 좀 안에 덧 대는게 더 들어갔으면 좋겠어. 면생리대를 잘 안 쓰는 게 냄새도 있지만 쓸까봐 불안한 것도 있잖아. 그거에 대한 보완을 좀 더 해줬으면 좋겠고. |
| | | 면생리대를 교체할 때 면생리대 안의 솜을 갈아줄 때 손에 피가 묻고 또 피가 묻어 있는 거를 가지고 다녀야 해서 불편했어요. |
| | | 전용 캐리어가 나오면 좋겠고. 쓰기 전 꺼는 그냥 파우치에 넣으면 되는데 이미 쓴 거를 다시 넣는 데에 부담감이 좀 있잖아? 그래서 그걸 잡을 수 있는 게 나왔으면 좋겠어. |
| | 신체적 불편 | 비위생적 | 진짜 빨기 귀찮아서야. 그게 생각보다 빨 때 비위생적인거 같아. 피가 다 고여 있는 상태에서 내가 다 손으로 주물러서 빨아야 되잖아. 일회용이 좋은 게 버릴 때 단칼같이 버리면 되잖아. 근데 면생리대는 한 번 더 쓰고 버려야 하냐? 이거 꼭 젖는 거잖아? |
| | | 사용 후 빨기 귀찮은 거… |
| | | 면생리대는 1~2시간 간격으로 계속 교체해야 하고 계속 가지고 다녀야 해서 불편해요. |
| | | 경제적 이점 | 시중에 파는 것도 적어도 일 년은 쓸걸? 그러니까 이게 세탁기에 막 넣는 게 아니라. 손으로 주물러서 빠는 거니까 해지는 현상이 일반적인 것보단 적지? 그래서 장기적으로 쓸 수 있어. |
| | | 사용 편리 | 이건 통풍이 되더라고. 그래서 살짝 뒤랄까 답답함이 없어. 그래서 착용했을 때 달라. 시중에 파는 거는 그 살짝 비닐이잖아. 근데 이건 안부터 끝까지 다 천이잖아. 그래서 확실히 막힘에 대한 불편함은 없어. |
| | | 심리적 안정 | 나는 조금 일회용보다 늦게 같았어. 왜냐면 이게 막 넘쳐나는게 아니냐 보니까. 이렇게 표현하는지 모르겠는데. 피를 애가 다 빨아들였다 싶을 때 같았어. |
| | | 면생리대에 대한 거부감은 크지 않은 것 같아. |
| | | 면생리대는 엄청 뽀송뽀송하고 생리통도 없어지고. |
| | | 근데 살만한 가치는 있어. 진짜 생리통 없어지고. |
| | | 확실히 좋지. 그러니까 필요에 없었던 생리양이 준다고 할까? 생리통도 줄고. 확실히 안 쓰고 쓴 거 차이는 있어. 그리고 확실히 냉도 많이 안 나왔어. |
| | | 면생리대 사용할 때는 아예 생리통이 없었고 허리가 아프다거나 하지는 증상이 없었는데… |
