# 랜딩 예시 질의 말투 고르기 (2026-10-16)

메인 화면 예시 질의 여섯 개가 '~찾아줘'(도서 셋)·'~궁금해'(논문 셋) 두 말투뿐이라는 사용자 지적으로, 주제는 그대로 두고 말투만
바꿀 후보를 운영 검색으로 견준 1회성 실험이다. 바꾼 문장은 `frontend/pages/index.vue` 의 `SUGGESTIONS`(브랜치
`fix/landing-example-variety`).

- `candidates.json`(1차, 주제 6 × 말투 5)·`candidates_r2.json`(2차 — 도서관 분야 다른 주제 셋과 현대시 말투, 1차 문장 둘을 기준점으로)
- `fetch_results.py [_r2]` — 화면과 같은 인자로 운영 검색에 넣는다. 도서 `POST /api/books/search {top_k 10, use_rewrite true}`,
  논문 `POST /api/papers/search {top_k 20, use_rewrite false}`. 상위 10건(화면 기본 순서)을 `results/` 에, 질의 문장을 가리고 목록
  순서를 섞은 판정 묶음을 `judge/` 에, 열쇠를 `judge_key*.json` 에 둔다. 도서 검색은 검색 기록을 남기므로 이 실험 전용 세션 id 를 쓴다.
- 판정(LLM 에이전트 워크플로, 주제마다 셋 — 처음 온 이용자를 돕는 사서·엄격한 주제 전문가·시연을 보는 심사위원 관점) — 모든
  목록의 모든 항목을 관련 2·일부 1·무관 0 으로. `tally.py` 가 말투마다 상위 10건(만점 20)·상위 5건(만점 10) 점수를 센다
  (`tally.json`·`tally_r2.json`, 원자료 `judge_result*.json`).
