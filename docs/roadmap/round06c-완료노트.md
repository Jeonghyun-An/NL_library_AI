11. **일반 틀 비율은 계획 흔들림이 커서 5문항으로 가르기 어렵다** — 대조군은 두 갈래의 계획 입력이 같은데(갈래 1 의 넓힌 질문이 원 질문 그대로) 일반 틀이 7/12 · 10/12 로 갈렸고, 같은 방식(스위치 0)의 갈래 0 도 06b 참고 25/30 · 본 실행 24/30 · 단독 실행 21/30 으로 움직였다. 본 실행 두 갈래의 차이(24 → 23)는 이 폭보다 작다.
12. **범위 용어와 자기점검 과잉 제외의 상호작용** — 두 실행 모두 범위 용어를 붙인 갈래에서 제외 판정의 관련이 늘었다(본 실행 20/80 → 60/126, 단독 실행 20/59 → 34/99). 같은 갈래에서 관련 편수가 줄고(68 → 66, 68 → 62) insufficient 가 늘었다(16 → 23, 15 → 18). 합성 검색어와 하위질문 기준 자기점검이 어디서 어긋나는지는 가르지 않았다 — '정밀하게' 가 기본 선택이면 이 동작이 기본이 된다.
13. **군더더기 변형** — '국내 학술논문 코퍼스에서'(computing 갈래 0 하위질문)·'국내 학술논문은'·'국내 학술논문의'(csr 갈래 1)·재검색 제안의 '국내 학술 논문' 은 `QUERY_FILLERS`(글자 그대로 '국내 학술논문에서')가 떼지 않는다. 문장 가운데의 '국내 학술논문에서' 를 떼면 문장이 어긋난다(csr 6번째 '…영향에 대한 제시하는 한계점…' — §5-4). 이월 3 과 함께 정한다.
