(식 3) α_ij* = α_ij / α_jj = (ΔX_i / ΔY_j) / (ΔX_j / ΔY_j) = ΔX_i / ΔX_j

여기서 α_ij*을 산출-산출승수라고 칭한다. 이제 이들 승수 행렬 (I - A**)^-1 = [α_ij*]은 내생부문-내생부문의 관계를 매개하는데, (I - A**)^-1의 j번째 열의 각 원소들은 산업 j의 산출이 1단위 변화 때 각 산업의 산출이 얼마만큼 변화할 것인지를 나타낸다. 산업 j가 산출을 일정수준 X_j까지 증가시킬 경우 벡터 (I - A**)^-1을 선곱하면 (post-multiply) 외생적으로 결정된 산업 j의 산출로 인하여 경제의 각 산업으로부터 필요한 총 산출의 벡터를 다음과 같이 계산해낼 수 있다.

(식 4) X = (I - A*)^-1 X

한편 앞서 도출한 리츠-스폴딩(Ritz-Spaulding) 모형은 공급측 모형으로부터 유도할 수 있는데, 이는 부가가치-산출의 관계를 매개하는 공급측 모형인 (식 2)의 고쉬(Ghosh) 모형으로부터 시작한다. 고쉬(Ghosh) 역행렬의 원소 β_ij는 β_ij = ΔX_j / ΔW_i 또는 ΔX_j = ΔW_i β_ij를 나타내는데, 특정 산업 i의 부가가치 변화에 따른 여타 j부문의 산출변화를 유도한다. 이로부터 유도한 리츠-스폴딩(Ritz-Spaulding) 모형을 통해 공급측 면의 산업 i의 산출변화로부터 유발되는 산업 j의 산출변화를 분석할 수 있다. 수요측 면 전개식과 동일한 과정을 따르면 아래의 (식 5)와 같이 정리할 수 있다.

(식 5) β_ij* = β_ij / β_ii = (ΔX_j / ΔW_i) / (ΔX_i / ΔW_i) = ΔX_j / ΔX_i

β_ij와 β_ii의 비율에 의해 정의된 또 하나의 산출-산출 승수는 공급산업 i의 산출변화와 수요산업 j의 산출변화를 매개하는데, (I - B*)^-1 = [β_ij*]에 산업 i에서 X_i' 만큼의 교란이 발생했을 때 공급지장벡터 X'를 선곱하면 특정 산업에서 일어난 교란이 유발하는 각 산업의 직·간접적 파급효과를 구할 수 있다.
