# 참고문헌 목록 조각 거르기 — 운영 근거 회귀 확인 (2026-10-14)

딥리서치 보고서·이어가기의 근거 대목이 논문 끝 참고문헌 목록 조각인 문제(인용칩에 서지 목록이 뜨고 '겹치는 대목 문장을
찾지 못했습니다', 생성이 참고문헌 항목을 논문 내용처럼 씀, 참고문헌 속 제목만 맞은 무관 논문이 근거가 됨)를
`app/services/research/bibliography.py` 의 `looks_like_bibliography` 로 `explorer.is_source_passage` 에서 거른다.
이 폴더는 그 규칙을 운영 보고서 48개의 근거 청크에 돌려 본 1회성 확인이다. DB·Milvus 에 쓰지 않고, 운영에는 GET 만 보낸다.

| 파일 | 역할 |
|---|---|
| `count_bibliography_evidence.py` | GET `/api/research/{job_id}` 응답 폴더를 읽어 근거별·청크별로 참고문헌 판정을 센다. `--fetch <주소>` 면 `job_ids.txt` 의 잡을 먼저 받는다 |
| `job_ids.txt` | docs·research 에 적힌 연구 id 가운데 보고서가 있는 48개 |
| `result.txt` | 이 브랜치 규칙으로 센 결과와 걸린 청크 154개 목록(앞 70자) |

## 결과

| | 조사 규칙(초안) | 커밋한 규칙 |
|---|---|---|
| 서로 다른 근거 청크 869개 중 참고문헌 | 158 | 154 |
| 인용 근거 839건 중 첫 대목이 참고문헌 | 173 (21%) | 168 (20%) |
| 인용 근거 839건 중 대목 전부 참고문헌 | 89 (11%) | 86 (10%) |

조사 초안에서 두 군데를 더 좁혔다 — 본문으로 남기는 쪽으로 기운 것이다(놓친 참고문헌은 지금과 같고, 잘못 거른 본문은 근거를 잃는다).

1. 머리 없는 목록은 **서로 다른 서지 꼴이 둘 이상**일 때만 참고문헌으로 본다. 꼴 하나만 되풀이되는 본문 — 연구문제 번호 목록
   `- 1) 공공도서관…어떠한가?`(밴쿠버 `- 49) Camacho` 와 같은 꼴), 영문 본문의 번호 인용 ` [3] `(IEEE `- [30]` 과 같은 꼴),
   법률 번호 `법률 제8029호` — 를 초안은 걸렀다(`app/tests/test_research_bibliography.py` 의 합성 본문 4개 모두 초안에서는 걸린다).
   대가로 꼴 한 가지만 있는 한국어 목록 4개를 놓친다: `KCI_FI001414097__0026`·`KCI_FI002065605__0042`·`KCI_FI002065605__0043`·
   `KCI_FI002537295__0024`.
2. 서지의 `연도.` 꼴에서 날짜 `2006. 10. 4.` 를 뺐고, 머리 낱말에서 단수 `Reference`(`Reference service` = 참고봉사)를 뺐다.
   운영 표본에서는 바뀐 판정이 없다.

새로 걸린 청크는 없다(초안 158개 ⊃ 커밋 154개). 조사 보고의 사례 — d60a5dc1 E2·E4·E10·E11·E13·E16·E8 둘째 대목, 85d2bc0e E11(수협)·
E13(특화도서관), 이어가기 prior.g1·gap 의 참고문헌 대목 8건 — 은 모두 걸린다.

검토 반영(10-14) 뒤 다시 세어도 `result.txt` 가 글자 하나 바뀌지 않는다. 고친 것은 본문 쪽으로만 더 기운다 — 서술 종결이
'다' 와 마침표 사이의 괄호 인용(`…하였다(김철수, 2012: 45-67).`)·마침표 뒤에 붙은 각주 번호(`.12)`)·닫는 따옴표를 넘어
세어 본문 청크 234개의 서술 수가 늘었고(걸린 154개는 0개), 청크 첫머리 머리는 뒤에 소문자 낱말(`Bibliography instruction`)이나
띄어 쓴 한글 낱말 둘(`참고문헌 분석에 관한`)이 이으면 머리로 보지 않으며(표본에서 바뀐 청크 0개), 머리 갈래도 영어 서술을 센다.

## 남은 것

- 놓침: 짧은 영문 서지·쪽 표기 없는 꼴(`KCI_FI001378107__0030`·`KCI_FI002538124__0051` 등)과 위 4개. 지금보다 나빠지지는 않는다.
- 본문 한 문장 + 참고문헌인 청크(`KCI_FI000965838__0050`·`KCI_FI001267084__0022`)는 걸려 맺음 한 문장을 잃는다.
- 영어 논문 비중이 큰 질의는 표본이 적다. 배포 뒤 예시 질문 1~2개로 근거 수·소요 시간(critic insufficient → 재검색)을 본다.
