# 딥리드 답변 규칙 — 부스 점검 증상 고치기 (2026-10-26)

프론트 세션이 부스 체험 질문을 운영에서 점검하다 찾은 딥리드 증상 셋(사용자 결정: 대회 전에 지시문만 고친다).

1. 브로셔 예시 '이 연구논문에서 주장하고자 하는 바는 무엇인가요?'(KCI_FI000862072) — "제공된 [참고 내용]만으로는 … 파악하기
   어렵습니다"로 얼버무리고 안쪽 이름 '[참고 내용]'이 답에 나왔다. 대목은 이론·방법·표 설명만 뽑혔고, 이 논문은 요약(summary)이
   비고 초록만 있어 시스템 프롬프트의 [논문 요약]이 '요약 정보 없음'이었다.
2. 소나기 '마지막 부분은 어떻게 마무리되나요?' — 결말 대목을 못 뽑아 "자료에 포함되어 있지 않습니다"로 단정.
3. 답 글에 '[쪽 정보 없음]'·'[표 4-2, 쪽 정보 없음]' — 쪽 없는 서지·초록 청크(chunk_idx -1)와 논문 표 설명(보강) 청크의 문맥 머리를
   모델이 옮겨 적었다(첫 쪽 문제가 아니다 — 표 설명은 본문 뒤쪽 내용).

## 바꾼 것

- `app/domains/nl_library/prompts/book_chat.yaml`·`book_chat.paper.yaml` 답변 규칙
  - [참고 내용]은 가까운 대목만 뽑은 것 — 대목을 먼저 근거로 삼는다. 처음·마지막·결말은 자료 전체 기준이고, 대목에 없으면 요약으로 답한다.
  - 대목에 없지만 요약에 있으면 요약으로 답한다(쪽 없이).
  - 자료 전체의 목적·주장·결론·의의(책은 줄거리의 흐름도)는 요약으로 큰 줄기를 먼저 답한다.
  - 둘 다 없으면 "찾은 본문에서는 확인하지 못했습니다" — 자료 전체에 없다고 단정하지 않는다('…다루지 않습니다' 삭제).
  - 답 글에 안쪽 이름([참고 내용]·[자료 요약]/[논문 요약]·[핵심 주제]·[쪽 정보 없음])을 쓰지 않는다.
  - 쪽 언급 두 줄(대목 머리 쪽 번호만·[쪽 정보 없음] 대목엔 쪽 없음)은 그대로다.
- `app/services/chat/book_chat.py` — 요약이 비면 초록을 요약 자리에 싣는다(`book.summary or book.abstract`). 대량 적재
  논문은 요약 없이 초록만 있는 것이 많다.
- 대목 고르기(6개·리랭크 없음·짧은 자료 전부 넣기 등)는 바꾸지 않았다 — 대회 뒤.
